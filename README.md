# AI Video Production Pipeline

"How Computers See Color" — a 2-minute AI-narrated explainer video, built
by an automated pipeline: text-to-speech, AI-generated images, AI
image-to-video on 4 flagged shots (with automatic fallback if that fails),
text overlays, and ffmpeg assembly. See `PIPELINE_LOG.md` for the full
design rationale, iteration, and dead ends.

## What's in this folder

| Path | What it is |
|---|---|
| `shots.json` | The 17-shot visual design: narration, image prompts, camera motion, overlay text |
| `pipeline.py` | The entire pipeline, one script, `shots.json` → `output/final.mp4` |
| `PIPELINE_LOG.md` | Workflow, per-step rationale, iteration, dead ends, evaluation |
| `README.md` | This file |
| `run_log.json` | Generated by running the pipeline — every prompt, seed, endpoint, and retry actually used |
| `output/final.mp4` | The final rendered video |
| `failures/` | Screenshots of bad outputs referenced in the log |
| `cache/` | Generated by running the pipeline — per-stage intermediate files (audio, images, clips). Not committed; regenerates automatically. |

## Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install requests pillow edge-tts
brew install ffmpeg          # macOS; use your OS's package manager otherwise
```

Add your Pollinations API key (from enter.pollinations.ai) either as an
environment variable or in a local `.env` file — the pipeline loads either:

```bash
echo "POLLINATIONS_KEY=your_key_here" > .env
```

## Run

```bash
python3 pipeline.py
```

Builds `output/final.mp4` end to end. Useful flags:

- `--stages tts,images` — run only a subset of the 7 stages
- `--only s01,s06` — target specific shot ids
- `--force` — ignore the cache and regenerate

Stage order: `concept -> tts -> images -> animate -> overlay -> clips ->
concat`. See `PIPELINE_LOG.md` section 2 for why it's ordered this way.

## Note on the `animate` stage

AI video generation needs a funded Pollinations account. On a free/
zero-balance key, every `animate`-flagged shot automatically falls back to
a still image with camera motion instead of crashing the run — this
happened in the actual submission and is documented in `PIPELINE_LOG.md`
section 5.
